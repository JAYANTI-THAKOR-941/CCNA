# Networking practical path

Use Cisco Packet Tracer or an isolated authorized classroom network. The examples are supplemental original exercises, not an official Cisco course. Interface names depend on the selected virtual device.

1. LAN connectivity and IPv4 addressing
2. Subnetting and VLSM
3. Switch access VLANs and trunks
4. Router interfaces and static routing
5. DHCP and DNS concepts
6. IPv6 addressing
7. Routing and switching troubleshooting
8. Secure device management concepts

See [lab workbook](labs.md) and [subnet worksheet](subnetting.md). Record results in observation-log.csv.
