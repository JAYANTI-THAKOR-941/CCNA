# CCNA networking practice academy

Supplementary classroom roadmap; not an official Cisco syllabus. Use Packet Tracer or an isolated authorized lab.

| Module | Concepts | Practice |
|---|---|---|
| 1 | LAN, WAN, network devices, Ethernet | Build a two-PC LAN |
| 2 | OSI and TCP/IP | Trace encapsulation conceptually |
| 3 | IPv4, CIDR, VLSM | Plan three LANs |
| 4 | Switching and MAC learning | Inspect a switch forwarding table |
| 5 | Access VLANs and trunks | Separate two departments |
| 6 | Routing and gateways | Route between two subnets |
| 7 | Static and dynamic routing concepts | Compare route choices |
| 8 | DHCP and DNS | Test address allocation and name resolution |
| 9 | IPv6 | Configure and verify a local IPv6 LAN |
| 10 | Wireless and security | Review segmentation and WPA settings |
| 11 | Monitoring and troubleshooting | Diagnose wrong addressing |
| 12 | Automation foundations | Read structured network inventory |

Use [guided labs](LABS.md), [assessment and answers](ASSESSMENT.md), and [lab report template](LAB_REPORT.md).
